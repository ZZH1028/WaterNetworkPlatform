# 模型输入参数说明文档
## 一、水位预测输入文件（demo_pred_input.json / real_pred_input.json）
### 全部固定入参（接口字段不可修改、增减）
| 参数名 | 数据类型 | 含义 | 取值范围 | 对应GIS数据源 |
| station_id | 字符串 | 雷达水位站编号 | 1~194 | data/gis/station.txt |
| current_level | 浮点数 | 当前河道吴淞水位(m) | 0 ~ 8 | 现场实测水位 |
| rainfall | 浮点数 | 时段累计降雨量(mm) | 0 ~ 200 | 雨量监测 |
| tide_level | 浮点数 | 外河潮位(m) | 2 ~ 5 | 外河潮位站 |
| gate_factor | 浮点数 | 闸门排水影响系数 | 0 ~ 1 | 闸泵调度配置 |
| pump_factor | 浮点数 | 泵站排水影响系数 | 0 ~ 1 | 闸泵调度配置 |
| hours | 整数 | 预测时长（小时） | 1 ~ 72 | 业务自定义 |
| created_by | 字符串 | 任务创建操作人员 | 任意文本 | 操作人记录 |

### 文件区分
1. demo_pred_input.json：本次验收演示模拟输入，用于交付验收
2. real_pred_input.json：后续迭代接入无锡新吴实测数据专用输入，字段结构完全不变，仅数值替换真实监测值

## 二、调度权重输入（demo_schedule_weight.json）
双调度目标权重，用于三套调度方案综合打分
1. 防洪安全：数值越大，方案越优先压低最高水位、降低洪涝风险
2. 能耗控制：数值越大，方案越优先减少闸泵运行、节约用电

## 三、调度约束输入（demo_schedule_constraint.json）
水利工程硬性运行限制，超出限制后调度方案会自动修正参数
1. max_gate_opening：闸门允许最大开度百分比
2. max_pump_hours：单日泵站最长运行总时长

## 四、使用规范
演示模型与实测真实模型共用同一套输入字段，接口完全统一，无需修改代码，仅替换数值即可切换数据源。
