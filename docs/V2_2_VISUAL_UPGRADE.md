## 已实现

- **河道三维研判工作台**：将原始断面重采样并连接成可旋转的河槽表面；可切换河段与单断面，分别控制河床、测点、断面线和参考水面。
- **可读的模型视角**：默认聚焦选中断面，保留俯视、断面正视和全河段视角。垂向显示比例可以调整，数值计算始终使用原始尺寸。
- **水面与断面联动**：参考水平面按河床三角形裁剪；横断面同步显示实际湿润部分，避免用整块矩形模拟泛滥范围。
- **可复核的几何指标**：分段积分计算实测范围内的过水面积、湿润宽度、湿周和水力半径。超过一侧实测岸端时显示边界提示。
- **过程回放**：支持播放、暂停、拖动时刻和速度控制。演示过程有明确标识；已导入的站点时序可作为人工选择的参考，但不自动宣称其代表该断面水位。
- **空间对象联动**：增加河道与站点检索、对象高亮、资料抽屉、对应断面入口及上下文问答；提供俯视、斜视、环绕、朝北、缩放、名称和图层控制。
- **界面与追溯**：统一深色面板、数字排版、状态栏和工具条，扩大有效工作区域，适配手机；支持原始断面 CSV 和包含原始断面的研判快照 JSON 导出。
- **资源与发布**：固定 Cesium、Three.js 等依赖版本，构建时校验 npm 包 SHA-512，三维引擎随站点发布；增加部署后的真实浏览器验收。

## 数据边界

三维河槽来自 `data/gis/river.txt`：305 个断面、19,317 个测点。断面保持原始本地平面坐标和吴淞高程；断面间按文件顺序插值，仅用于观察几何，不代表已验证的水流拓扑或地形测绘成果。

GIS 实景场景使用在线卫星影像、在线地形及工程位置符号。卫星影像贴地与精细倾斜摄影模型是不同的数据产品。当前没有授权的建筑级实景 3D Tiles；平台保留其配置入口，不以虚构建筑替代。外部服务失败时保留可用的本地对象和独立断面模型，并如实显示状态。

参考水面与几何指标没有求解水动力方程，不是洪水淹没、流量或正式预报成果。当前没有真实水情接口；默认显示待接入，合成演示需显式开启。本地检索可直接使用，生成式大模型需要配置服务端接口。

## 验证方法

`npm test` 包含既有业务测试及断面计算测试；新增测试覆盖解析几何、边界超出、干断面、多个独立湿区、垂直岸壁、重复和无效测点、重采样、方向对齐、三角形裁剪及视觉比例独立性。

```bash
npm test
python -m unittest discover -s tests -p test_rag_api.py -v
python scripts/ingest_public_manuals.py
python scripts/build_web.py
python tests/browser_smoke.py --url <已发布的完整网站地址> --revision <build.json 中的 revision>
```

浏览器验收检查实际 Cesium/Three WebGL canvas、河道到断面的联动、水位变化后的面积、模型 canvas 复用、视角与图层、回放暂停、上下文问答、手机导航与横向溢出，同时记录未捕获脚本错误、站内资源失败和外部底图状态。GitHub Actions 在发布后执行该检查，结果和截图保存在 `published-site-browser-check` 构件中。
