# 澜枢 · 平原感潮河网智能平台 2.1

三维卫星影像与地形、真实河网 GIS、断面三维查看、水利知识检索与操作助手、监测导入、情景推演、方案比选和本地备份。

- 新版源代码：`web/`；可复现构建：`scripts/build_web.py`。
- 专业知识：47 条中文笔记 + 5 部官方技术手册，1,753 页 / 3,477 个英文原文片段。支持 PDF、DOCX、TXT、MD、JSON、CSV 导入和引用溯源。
- 默认 AI 为可直接使用的本地检索；生成式解释通过 `api/server.py` 接入服务器配置的大模型。
- 所有 GIS 地图入口改为 Cesium 三维实景；原业务后台保留并加入水利助手。
- 河海大学校徽与黑色为主、深蓝为辅的统一界面，适配手机与桌面。
- 水情监测支持 HTTPS 接口轮询、时效质控、滚动线性趋势预报及观测/预测超限提醒。当前没有真实接口，默认待接入，另有明确标记的合成演示。
- 平台内弹窗、未读数量、确认、处置说明、恢复复核与归档；页面打开时生效，尚无短信、邮件或后台常驻通知服务。
- 预测采用未经本地率定的趋势基线；情景推演仍为演示，不冒充实测模型结果。

完整启动、GitHub Pages 首次开通、模型连接和适用边界见 [部署说明](docs/V2_DEPLOYMENT.md)。

```bash
python -m pip install 'pypdf>=5,<7'
python scripts/ingest_public_manuals.py
python scripts/build_web.py
python api/server.py
```

打开 http://127.0.0.1:8000 。GitHub Actions 会自动构建，仓库管理员首次需在 Settings → Pages 中将发布源设为 GitHub Actions。

# 水网工程水力调控智能平台 V1.0 指挥大屏首页版

本版本基于 V1.0 公网展示版升级：**核心后台和数据逻辑不删除，只重构公开首页为水利指挥中心/数字孪生大屏风格**。首页中间直接加载真实 GIS 河网，左右展示实时水情与预警，下方提供现有功能的一键入口。

## V1.0 首页新增

- 深蓝水利指挥大屏视觉：首页、导航、状态卡、地图和快捷入口统一为水利数字孪生风格。
- 首页 GIS 一张图：读取 `station.txt`、`gate_pump.txt`、`river_network.geojson`，使用深色底图显示河网、站点和闸泵。
- 实时信息侧栏：读取业务数据库最新水位、24 小时降雨、预测任务和当前预警。
- 8 个快捷入口：GIS 全景、3D 数字孪生、监测图表、水动力预测、智能调度、风险预警、方案比选、系统管理。
- 深链接登录：点击需要权限的后台功能时先进入登录页；登录成功后自动跳到用户有权限访问的目标页面。
- 后台侧栏同步优化：修复浅色块/白字对比问题，改成深色半透明导航菜单。
- 手机/窄屏保留响应式布局。

> `docs/homepage_command_center_reference.png` 为视觉参考图；实际首页由 Streamlit/Folium/业务数据实时渲染，不是把参考图当作静态背景。


本版本在 V1.0 Web 门户基础上进一步完成公开首页视觉升级、二维 GIS、真实河道断面三维数字孪生展示，以及临时/正式公网部署入口。
